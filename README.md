# 外发业务与操作指南

以完整的业务讲解页面呈现三类外发。先说明业务区别，再逐步演示 8 个场景；当前节点的系统、菜单、按钮、扫码对象、结果和交接直接展示在图下方。支持播放、暂停、上一步、下一步和点击节点。异常按原因分支；正常演示跳过按需补记，遇到未核实的交接自动暂停。完整系统泳道图作为折叠对照保留。

当前版本：2026-10-15。包含 8 个场景：缝制加工商配置、每批缝制外发、少货与加工异常、裁片退回重派、外印工厂配置、每批外印生产、SRM 转印切割缝制与交付、切割异常回退。

本页依据固定代码快照与已有 SOP 整理，尚未逐项验证生产权限和现场工位；待核实项见网页“核实范围”。

## 发布

GitHub Pages 从 main 分支根目录发布。更新 guide-data.js（操作详情）、report-data.js（业务讲解）、app.js（逐步演示）、report.css（页面排版）、reference-view.js（入口与证据）、flow-data.js / flow-view.js（完整泳道图）、styles.css 和 index.html 后推送 main，页面自动更新。固定网址不变，既有场景深链接保持兼容。

站点只包含说明页面，不连接业务系统，不包含账号凭据、真实入口凭证或生产订单数据。
