# 外发业务与操作指南

以三条主线总览和八张系统泳道图呈现业务流转。节点标明系统、菜单和按钮；点击节点查看操作人、扫码对象、状态和下道交接。条件用菱形分支，尚未核实的交接用虚线。支持缩放、大图和打印；详细手册作为折叠补充。

当前版本：2026-10-15。包含 8 个场景：缝制加工商配置、每批缝制外发、少货与加工异常、裁片退回重派、外印工厂配置、每批外印生产、SRM 转印切割缝制与交付、切割异常回退。

本页依据固定代码快照与已有 SOP 整理，尚未逐项验证生产权限和现场工位；待核实项见网页“核实范围”。

## 发布

GitHub Pages 从 main 分支根目录发布。更新 guide-data.js（操作详情）、flow-data.js（图的节点与分支）、flow-view.js（图形呈现）、app.js、styles.css 和 index.html 后推送 main，页面自动更新。

站点只包含说明页面，不连接业务系统，不包含账号凭据、真实入口凭证或生产订单数据。
